Research Internship

Agent System Security · Fudan University

We are recruiting excellent, self-driven students as research interns, with the goal of publishing papers at top security venues (e.g., the "Big Four"). The current focus is on the security of LLM-based agent systems.

面向优秀、自驱力强的学生招收科研实习生，以在安全顶级会议（如“四大”）发表论文为目标。 当前主要研究方向为智能体（LLM Agent）系统安全。

Research Directions

  • Security of agent frameworks and their tool-use / permission mechanisms
  • Attacks and defenses in multi-agent and tool-calling pipelines
  • Memory, RAG, and context security in agent systems
  • Empirical security measurement of real-world agent deployments
